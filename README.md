# derickdanes.github.io

Portofolio pribadi Derick Danes — mahasiswa Sistem Informasi Universitas Mikroskil, Medan.

Satu halaman statis: HTML, CSS, dan JavaScript tanpa framework. Tidak ada proses build.

- `index.html` — seluruh halaman (markup, gaya, dan skrip)
- `assets/` — foto dan tangkapan layar proyek

Palet dan elemen pemilih kursi di bagian atas halaman diambil dari S-TIX,
aplikasi pemesanan tiket bioskop yang saya kerjakan.
