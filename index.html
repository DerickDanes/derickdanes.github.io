2026 Proyek pribadi · solo

Money Clarity Planner

Aplikasi PWA pencatat keuangan pribadi dalam Rupiah. Dibuat karena mencatat pengeluaran dari struk itu melelahkan — jadi struknya yang dibaca aplikasi, bukan diketik ulang.

  • Transaksi, akun, kategori, kantong anggaran (envelope budgeting), target bulanan, sampai pencatatan investasi dan mata uang asing.
  • Fitur scan struk: gambar diproses OCR lalu dibaca AI vision, hasilnya langsung jadi transaksi siap simpan.
  • Arsitektur berlapis — domain → data → antarmuka. Logika uang dipisah dari React dan Supabase supaya bisa diuji sendiri lewat unit test.
  • Skema PostgreSQL dengan Row Level Security, jadi data tiap pengguna terkunci di tingkat basis data, bukan cuma di kode.

S-TIX — Pemesanan Tiket Bioskop

Aplikasi web pemesanan tiket dengan denah kursi. Dibuat tanpa framework sama sekali: HTML, CSS, dan JavaScript murni, sekitar 650 baris logika.

  • Alur bertahap: data pemesan → bioskop → film → jam tayang → kursi. Tiap langkah terkunci sampai langkah sebelumnya diisi, jadi tidak ada pemesanan setengah jadi.
  • Denah kursi 8×10 yang dibangun ulang setiap kali data berubah, lengkap dengan status tersedia, dipilih, dan terisi.
  • Deteksi konflik sebelum menyimpan: kalau kursi yang dipilih ternyata sudah diambil, pemesanan ditolak dan denah dimuat ulang.
  • Riwayat pemesanan disimpan di LocalStorage dengan nomor urut otomatis, bisa dihapus dengan konfirmasi.
  • Kontribusi saya dalam tim: menulis seluruh logika JavaScript aplikasi (576 baris) dan sebagian besar CSS, serta membuat halaman riwayat pemesanan. Bisa diperiksa dari riwayat commit di repositorinya.
